# SkyGazing - Astronomy & Celestial Observatory Portal

A comprehensive educational astronomy and celestial sky observation web portal built with **HTML5**, **CSS3**, and **JavaScript**.

## ✨ Key Features
- **Celestial & Planetary Showcase**: Interactive guides to planets, stars, constellations, and celestial phenomena.
- **Astronomy Documentation & Guides**: Curated educational materials and observational research.
- **Embedded Media & Virtual Tours**: Video documentaries and astronomical imagery collections.
- **Responsive Layout**: Designed for seamless viewing across smartphones, tablets, and desktop workstations.

## 📁 Project Structure
- `index.html` - Main observatory portal landing page
- `script.js` - Interactive scripts and gallery controls
- `style.css` - Custom space-themed styling and responsive layouts
- `images/` - High-resolution celestial and astrophotography assets
- `videos/` - Space exploration video clips
- `Libraries/` - Third-party helper libraries and scripts
- `Documentation/` - Project documentation and research notes

## 🚀 Getting Started
Clone the repository and open `index.html` in your web browser:
```bash
git clone https://github.com/abdullah3111/skygazing-astronomy-portal.git
cd skygazing-astronomy-portal
# Open index.html in your browser
```
